# assets/backgrounds/ — 배경 소재

04_background.py 가 여기서 소재를 고른다. 세로(9:16) 영상·이미지를 권장하며, 가로 소재는 05 렌더가 가운데를 잘라 채운다.

- 이 폴더 바로 아래: 모든 주제에 공통으로 쓰는 소재
- `{id}/` 하위 폴더 (예: `001/`): 그 주제에만 쓰는 소재. 있으면 공통보다 우선.
- 영상: .mp4 .mov .mkv .webm / 이미지: .jpg .jpeg .png
- 저작권이 확인된 파일만 넣는다. 출처와 라이선스를 `SOURCES.md` 에 적어 둔다.

소재가 하나도 없고 `USE_PEXELS` 도 꺼져 있으면 단색 그라데이션 배경을 자동 생성해 렌더가 멈추지 않게 한다.
