# sources/ — 대본 근거 문서

01_write.py 는 topics.csv 의 `sources` 열에 적힌 파일(세미콜론 `;` 구분)만 읽어
대본 프롬프트에 그대로 넣는다. 여기에 없는 내용은 대본에 쓰지 않는다.

## 파일 형식 (Markdown)

```
# 제목
출처: 기관명, 문서명, URL, 확인일
대상: (누구에게 해당하는 정보인지)

## 핵심 내용
- 한 줄에 사실 하나
- 숫자는 출처에 있는 그대로

## 주의 / 병원에 가야 하는 경우
- ...

## 금지 (대본에 넣으면 안 되는 것)
- 특정 약 이름, 건강기능식품, 치료법
```

## 규칙
- 공공기관(질병관리청, 보건복지부, 대한의사협회 등) 또는 학술 자료만 사용한다.
- `출처:` 줄이 없는 문서는 사용하지 않는다.
- 파일명은 영문 소문자와 밑줄만 사용한다. 예: `dehydration_summer.md`
